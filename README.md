# Online Library System

A React-based Online Library System that allows users to browse books, search for books, filter books by category, view book details, and add new books to the library.

## Features

-   Welcome/Home page
-   Book categories
-   Popular books
-   Browse all books
-   Filter books by category
-   Search books by title or author
-   View detailed information about a book
-   Add new books
-   Form validation
-   Redux state management
-   Dynamic routing
-   404 Page Not Found
-   Responsive design
-   User-friendly interface

## Technologies Used

-   React
-   Vite
-   React Router DOM
-   Redux Toolkit
-   React Redux
-   JavaScript
-   CSS

## Installation and Setup

Follow these steps to install and run the project on your computer.

### Prerequisites

Make sure the following software is installed:

-   Node.js
-   npm
-   Git

You can check whether Node.js and npm are installed by running:

``` bash
node -v
npm -v
```

### 1. Clone the Repository
Open a terminal and run:

``` bash
git clone https://github.com/patelparth2183/online-library
```

Replace `https://github.com/patelparth2183/online-library` with the URL of this GitHub repository.

### 2. Navigate to the Project Folder
``` bash
cd online-library
```

### 3. Install Project Dependencies
Run:

``` bash
npm install
```

This installs all dependencies listed in `package.json`, including React
Router, Redux Toolkit, and React Redux.

### 4. Start the Development Server
Run:

``` bash
npm run dev
```

Vite will display a local development URL in the terminal, usually:

``` text
http://localhost:5173/
```

Open this URL in your web browser to use the application.

### 5. Stop the Development Server
To stop the development server, press:

``` text
Ctrl + C
```
